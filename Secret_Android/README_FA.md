# پروژه Secret برای اندروید + سرور واسط

این بسته شامل سورس اپ اندروید (Kotlin + Jetpack Compose) و سرور واسط Python/FastAPI است. **این ZIP خودش APK آماده نیست.** برای ساخت APK باید پروژه در Android Studio ساخته شود و سرور نیز روی یک میزبان HTTPS منتشر شود.

## امنیت کلید API
- کلید API داخل اپ اندروید قرار داده نشده است.
- کلید را فقط در `server/.env` روی سرور قرار بده.
- چون کلید قبلی در چت ارسال شده، آن را لغو کن و یک کلید جدید بساز.
- کلید را در GitHub عمومی، داخل APK یا در پیام‌ها قرار نده.

## 1) راه‌اندازی سرور روی کامپیوتر برای آزمایش
نیازمند Python 3.10 یا بالاتر است.

```bash
cd server
python -m venv .venv
```

فعال‌سازی محیط مجازی:
- Windows: `.venv\\Scripts\\activate`
- macOS/Linux: `source .venv/bin/activate`

سپس:
```bash
pip install -r requirements.txt
```

فایل `.env.example` را به `.env` تغییر نام بده و مقادیر را تنظیم کن. `HORMOUZ_MODEL` باید نام مدلی باشد که حساب هرمز تو پشتیبانی می‌کند؛ مقدار `default` ممکن است نیاز به تغییر داشته باشد.

اجرای سرور:
```bash
uvicorn main:app --host 0.0.0.0 --port 8000
```

آدرس بررسی سلامت:
`http://127.0.0.1:8000/health`

## 2) اجرای اپ در شبیه‌ساز Android Studio
1. Android Studio را نصب و باز کن.
2. گزینه **Open** را بزن و پوشه اصلی `Secret_Android` را انتخاب کن.
3. اجازه بده Gradle همگام‌سازی شود و Android SDK 35 نصب باشد.
4. شبیه‌ساز را اجرا و دکمه Run را بزن.

اپ به‌طور پیش‌فرض از `http://10.0.2.2:8000` استفاده می‌کند؛ این آدرس فقط برای شبیه‌ساز اندروید به کامپیوتر میزبان اشاره می‌کند. برای گوشی واقعی، آدرس باید به سرور قابل‌دسترسی روی شبکه یا اینترنت تغییر کند. برای انتشار عمومی، از HTTPS استفاده کن.

## 3) تنظیم آدرس سرور
در `app/build.gradle.kts` این خط را پیدا کن:
```kotlin
buildConfigField("String", "API_BASE_URL", "\\"http://10.0.2.2:8000\\"")
```
آدرس سرور خودت را جایگزین کن، مثلاً `https://your-api.example.com`. دامنه نمونه است و باید دامنه واقعی خودت را وارد کنی.

## 4) ساخت APK
در Android Studio:
**Build > Build Bundle(s) / APK(s) > Build APK(s)**

فایل APK معمولاً در این مسیر ساخته می‌شود:
`app/build/outputs/apk/debug/app-debug.apk`

برای انتشار عمومی، از **Build > Generate Signed Bundle / APK** استفاده کن و کلید امضای انتشار را امن نگه دار. برای Google Play معمولاً Android App Bundle (AAB) مناسب‌تر است.

## نکات فعلی نسخه اولیه
- چت متنی و نگهداری محلی پیام‌های گفتگوی جاری دارد.
- دکمه گفتگوی جدید/پاک کردن، تاریخچه ذخیره‌شده را پاک می‌کند؛ چند گفتگوی جداگانه هنوز پیاده‌سازی نشده است.
- ارسال تصویر، میکروفون، تبدیل متن به گفتار، توقف پاسخ و نمایش کامل Markdown هنوز در این اسکلت اولیه پیاده‌سازی نشده‌اند.
- ارتباط واقعی با حساب Hormouz از این محیط آزمایش نشده است. نام مدل و شکل پاسخ ممکن است بسته به حساب/API نیاز به تنظیم داشته باشد.
- قبل از انتشار عمومی، محدودیت مصرف، احراز هویت کاربر، rate limiting، لاگ امن و سیاست حریم خصوصی اضافه کن؛ در غیر این صورت ممکن است دیگران از سهمیه API سرورت استفاده کنند.

## فایل‌ها
- `app/`: اپ اندروید
- `server/`: API proxy برای محافظت از کلید
## ساخت APK از طریق GitHub Actions (بدون کامپیوتر شخصی)
فایل `.github/workflows/build-apk.yml` برای ساخت APK در GitHub Actions اضافه شده است.
1. پروژه را در یک مخزن GitHub آپلود کن (ترجیحاً مخزن خصوصی).
2. در تب **Actions**، گردش‌کار **Build Secret Android APK** را اجرا کن؛ یا پس از push به شاخه `main` منتظر اجرا بمان.
3. پس از موفقیت، از صفحه اجرای workflow بخش **Artifacts** فایل `Secret-debug-apk` را دریافت کن.
4. این خروجی APK آزمایشی است و امضای انتشار برای فروشگاه‌ها نیست.

این روش به حساب GitHub نیاز دارد و ممکن است محدودیت مصرف Actions داشته باشد. از آنجا که من در این محیط Android SDK/Gradle نصب‌شده ندارم، APK را همین‌جا کامپایل و تست نکرده‌ام.
